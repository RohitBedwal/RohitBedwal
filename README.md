## 💫 About Me

### 👋 Hi, I'm a Junior Frontend Developer!

I'm a passionate developer who enjoys building modern, responsive, and user-friendly web applications. I primarily work with **React.js and JavaScript**, focusing on frontend development, reusable UI components, and creating seamless user experiences.

I have hands-on experience working on real-world projects, including e-commerce dashboards, POS systems, inventory management, stock management, and design systems. I enjoy solving practical problems through code and continuously improving my development skills. 🚀

- Creating reusable UI components and responsive interfaces.

**🤝 Looking for Help With**

**🌱 Currently Learning**

**💬 Ask Me About**

- Inventory management and reusable UI components.
